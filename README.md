# FanliQuant — 股票分析网站（最终完善版）

首页即分析网站：输入 A股代码，自动抓取真实行情/估值/行业/基金持仓，输出范蠡六维、值得买概率、真实概率、回测与排名。

## 打开

http://127.0.0.1:8787/

## 功能

- 个股分析：真实行情、PE/PB、行业景气、基金持仓
- 范蠡六维 V3：每维权重、得分、贡献分、占总分比例
- 值得买概率：Brier skill 收缩校准，输出组成与贡献占比
- 真实概率：Walk-Forward + Platt + Bootstrap CI + Brier
- 真实回测：复权、停牌过滤、佣金/印花税/滑点/冲击成本
- 每日值得看十支：按校准后值得买概率排名
- 我的收藏榜：本地收藏 + 自动排名
- 基金持仓：标注持有该股票的基金名称、基金公司、持股比例、报告期
- 合规：来源 URL、置信度、时间戳、免责声明

## 运行

```bash
node src/http_server.js
node test/server.test.js
```

## 数据源

- 东方财富公开 HTTP 接口（A股行情/估值/行业/基金持仓，非官方，置信度 0.65–0.75）
- SEC EDGAR / Company Facts（美股申报与财报）
- Baostock CSV/sidecar（A股备用）

## 免责声明

不构成投资建议；概率非保证；基金持仓来自公开披露，可能有滞后。
